# InfraGrid

**Design. Provision. Secure. Automate.**

InfraGrid is a Terraform-based infrastructure automation project for GCP,
covering reusable modules, CI/CD validation, security scanning, policy
enforcement, drift detection and cost governance.

## Status

Phase 1: repository foundation. **No infrastructure has been implemented or
deployed yet.** Everything listed in the project goals is planned.

## Planned capabilities

- Reusable Terraform modules (networking, IAM, compute, storage)
- Dev, staging and prod environment configurations
- GitHub Actions validation and plan workflows
- Checkov scanning and OPA/Conftest policies
- Drift detection and Infracost cost estimates

This README will be expanded as each capability is implemented and tested.
